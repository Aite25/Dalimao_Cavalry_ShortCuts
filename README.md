# Cavalry ShortCut —— 径向热盒

给 Cavalry 2.8.1 用的外部「热盒」（径向菜单）：`Shift+A`（脚本触发）在鼠标位置弹出，8 个扇区执行脚本 / 加图层 / 时间线操作，带搜索、搜索工具、设置页。

> 本版本对应 **v1.3.5**

---

## 1. 安装

1. 解压到任意目录（例如 `E:\dsh work\dsh_cavalry\Cavalry_ShortCut`）；
2. 双击 `Cavalry_ShortCut.exe` 启动（首次会弹 SmartScreen，点「更多信息 → 仍要运行」）；
3. 把 `scripts\Cavalry ShortCut Show.js` 复制到
   `%APPDATA%\Cavalry\Scripts\`
4. Cavalry 里给它绑定一个快捷键（默认示例为 `Shift+A`）：
   - Cavalry → 设置 → 快捷键，找到 `Cavalry ShortCut Show`
   - 注意：**脚本文件名不要改**，否则快捷键绑定会失效。

## 2. 呼出与关闭

| 操作 | 说明 |
|---|---|
| `Shift+A`（你绑定的脚本快捷键） | 在**鼠标位置**弹出热盒（圆心=鼠标） |
| `Esc` | 关闭热盒 |
| 中键拖动 | 移动热盒（可以拖到屏幕外） |
| 右键 | 取消 / 关闭 |
| 中心圆点 | 进入搜索菜单 |
| `Tab` | 从圆盘进入搜索菜单 |

> 呼出时**不做屏幕边界夹取**：贴着屏幕边缘呼出时圆心仍在鼠标处，往边缘方向甩鼠标也能选中该方向扇区。

## 3. 圆盘扇区

- 8 个扇区：`N / NE / E / D…` 按方位排列，每个扇区显示**图标 + 名称 + 快捷键**；
- **扇区快捷键**（默认一套 WASD 布局）：

```
      N  = W
NW = Q      NE = E
W  = A      E  = D
SW = Z      SE = C
      S  = S
```

- 呼出后**直接按该键**即可执行对应扇区（不用鼠标）；
- 也可以用鼠标点扇区；
- 空白处左键 = 执行当前悬停的扇区。

## 4. 热盒组与版本（页签）

顶部两行页签：

| 行 | 内容 | 作用 |
|---|---|---|
| 第一行 | `1 2 3 4` | 4 组热盒，**直接按数字键**或点击切换 |
| 第二行 | `无 / Ctrl / Shift / Alt` | 同一组热盒的 4 个版本（修饰键区分） |

- 共 `4 × 4 = 16` 套绑定；
- 单独按 `Ctrl` / `Shift` / `Alt` 切换版本；
- 呼出时总是从「1 · 无」开始。

## 5. 搜索菜单

`Tab` 或点中心圆 → 搜索菜单：

- **输入框是原生 Windows EDIT**：光标、`Ctrl+A` 全选、拖动选字、输入法、右键菜单都正常；
- 分类页签：`全部 / 脚本 / 形状 / 行为 / 工具 / 效果 / 操作`
  - **页签可拖动换顺序**（保存到 `Cavalry_ShortCut.ini` 的 `taborder=`）
  - **Shift + 滚轮**（任意位置）或滚轮落在页签行上 = 切换页签；
- 结果行显示：序号 / 图标 / 名称 / 键帽 / 类型标签；
- `↑↓` 选择，`Enter` 执行；
- 点击结果直接执行；
- **右键结果**：`绑定到热盒…` / `置顶`；
- 点面板外的区域 = 关闭面板；
- `Esc` = 返回圆盘。

## 6. 操作（时间线）

「操作」页签来自 `ops\*.js`，热更新：

| 名称 | 快捷键 | 作用 |
|---|---|---|
| 设入点 | `[` | 入点对齐播放头，内容整体后移 |
| 设出点 | `]` | 出点对齐播放头，内容整体后移 |
| 裁剪入点 | `Alt+[` | 入点对齐播放头，内容不动 |
| 裁剪出点 | `Alt+]` | 出点对齐播放头，内容不动 |
| 上一帧 / 下一帧 | `←` / `→` | 移动播放头 |
| 跳到起点 | `Home` | 播放头到 0 |
| 跳到图层出点 | `End` | 播放头到当前图层出点 |
| 整体入点对齐 | — | 多选图层整体平移，最早入点对齐播放头 |
| 整体出点对齐 | — | 多选图层整体平移，最晚出点对齐播放头 |

## 7. 设置菜单（齿轮）

```
[1] [2] [3] [4]
[无] [Ctrl] [Shift] [Alt]

    N            ← 左侧：8 个环状热盒，点击=选中（不会跳转）
NW      NE          中心显示当前「组 · 版本」
W   1·无   E
SW      SE
    S

[ 扇区快捷键（N）            W ]     ← 点击后按一个键，设置该扇区快捷键

        搜索并绑定到 N             ← 右侧：分类页签 + 搜索 + 结果
        [ 输入框 ]
        全部 脚本 形状 …           ← 滚轮/Shift+滚轮切页签
        ▸ 结果1
        ▸ 结果2
```

操作流程：

1. 齿轮（或 `F2`）进设置；
2. 左侧点一个扇区（选中，高亮）；
3. 右侧搜索并**点一个结果** → 立刻绑定到该扇区并写盘；
4. 需要改快捷键：点「扇区快捷键（N）」→ 按一个键（`0-9 / A-Z / F1-F12 / Space / \``）；
5. 「取消」= 丢弃本次改动并关闭；「确定」= 保存并关闭；右上角 **×** = 直接关闭；`Esc` = 关闭。

> 绑定新项目**不会**重置已有扇区快捷键。

## 8. 换脚本（热更新）

| 目录 | 页签 | 说明 |
|---|---|---|
| `actions\*.js` | 脚本 | 节点/图层脚本，例如 `Math.js`、`Duplicator.js` |
| `ops\*.js` | 操作 | 时间线操作，头部用注释声明名字与键帽 |

自定义脚本模板：

```js
// name: 我的操作
// key:  Alt+K
(function () {
    // 这里写 Cavalry 的 api 调用
    api.setFrame(api.getFrame());
})();
```

- 放进目录 → **下次呼出热盒**即出现在列表里（不需要重启程序）；
- 每次执行都会重新读文件，改内容立即生效。

## 9. 配置文件

| 文件 | 内容 |
|---|---|
| `Cavalry_ShortCut.json` | 16 组 × 8 扇区的绑定（名称/类型/值/快捷键） |
| `Cavalry_ShortCut.ini` | `hotkey=`、`ime=`、`opsmode=`、`taborder=` |
| `Cavalry_ShortCut_pinned.txt` | 搜索项置顶 |
| `Cavalry_ShortCut.log` | 运行日志（排查用） |

## 10. 排查

遇到「呼不出 / 看不见 / 点了没反应 / 操作不生效」，先看 `TROUBLESHOOTING.md`（24 个已踩坑点 + 30 秒排查清单）。

## 11. 已知限制

- 操作通过 Cavalry MCP（桥）执行，**首次**调用有 0.3s 左右延迟，之后很快；
- 模拟按键不被 Cavalry 接受，所以 `opsmode=keys` 仅作备用；
- 自签名证书只在本机可信，换机器仍会提示"未知发布者"。
